# Powtórka do sprawdzianu

Projekt edukacyjny do powtórzenia materiału z programowania obiektowego.

## Nauczasz się:
- **Klasy abstrakcyjne** - osoba (abstract class)
- **Dziedziczenie** - Uczen extends osoba
- **Zmienne statyczne** - LiczbaUczniow
- **Metody statyczne** - getLiczbaUczniow()
- **Gettery i settery** - enkapsulacja
- **toString()** - reprezentacja tekstowa obiektu
- **Konstruktory** - inicjalizacja danych
- **System.out.println()** - wyświetlanie w konsoli
